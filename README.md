# Machine Learning Lab 


This contains Python solutions for cleaning 
## 📂 Repository Structure

- **`pca2main`**: Contains the data cleaning script that handles inconsistent formatting, typos, negative values, and missing entries (`None`, `N/A`), exporting a clean dataset (`cleaned_titanic.csv`).
- **`decisiontree.py`**: Loads the cleaned dataset, encodes categorical features, and implements Decision Tree and Gaussian Naive Bayes classifiers to predict passenger survival.
